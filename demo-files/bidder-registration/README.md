BAC bidder registration demo files

Use these sample PDF files when testing the Register Bidder document uploads. The
files are generated as readable one-page PDF documents, not just renamed text
files, and are detected as `application/pdf`.

Suggested field mapping:

- valid-business-permit.pdf -> Valid Business Permit
- dti-sec-cda-registration-certificate.pdf -> DTI/SEC/CDA Registration Certificate
- bir-certificate-of-registration.pdf -> BIR Certificate of Registration
- mayors-permit.pdf -> Mayor's Permit
- philgeps-registration.pdf -> PhilGEPS Registration
- tax-clearance.pdf -> Tax Clearance
- omnibus-sworn-statement.pdf -> Omnibus Sworn Statement
- authorized-representative-valid-id.pdf -> Authorized Representative Valid ID
- other-supporting-document.pdf -> Other supporting documents required by BAC
